# Phase 4: Meta — Roster, Crystals, Floors Map, Rewards, Arena — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the fights a reason: a persistent roster you grow (stars, rank, level), crystals to pull champions from, a floor-by-floor campaign map over the Phase 3 `FLOORS`, post-fight rewards that feed the roster, an endless arena streak, and a title flow that ties it together, all headless-testable end to end.

**Architecture:** The meta is a pure data layer (`src/12_meta.js`: `Meta` with `Save.data` v2, `Stats.derive`, `Crystal.open`, `Quest`, `Rewards`, `Energy`) with no DOM, driven by a thin screens layer (`src/85_screens.js`: DOM overlays for title, map, roster, crystal, shop, arena) that only calls `Meta` and `G`. Fights start through `G.startFight({encounter, champ})` where `champ` is the roster entry whose derived stats override the def's hp/atk (cloned in G, as encounters already do). Determinism: every meta random (crystals) draws from `RNG(Save.data.seed++)`; wall-clock only in `Energy` via an injectable `now()`.

**Tech Stack:** unchanged.

**Spec:** Phase 1 spec + Phase 2/3 rulings + the rulings below.

## Rulings (2026-09-22)

1. **Campaign = floors, not "acts".** The map reuses `FLOORS` (Phase 3); a floor is a vertical path of its 5 nodes ending at the boss. Completing the boss unlocks the next floor. The Phase 1 outline's "3 chapters × 6 nodes" is replaced.
2. **Roster is the four champions** (carl, katia, donut, mongo); mobs and bosses are not collectible. Crystals therefore give stars/duplicates: a duplicate pull adds `+1 star shard`, 5 shards = +1 star (cap 5★).
3. **Currencies:** gold (node rewards, sells nothing yet), units (boss rewards; buy crystals), iso (level-up), class catalysts (rank-up). No real money, no timers except energy.
4. **Energy:** 10 max, 1 per node, regen 1 per 6 minutes via injectable `now()`; arena costs no energy.
5. **The "SPONSOR PERK KIOSK"** name and card layout come from Carls-Dash; its contents here are crystals and ISO packs.

## Global Constraints

Everything from Phases 1-3 (single built `index.html`, `file://`, 854x480, sim boundary, determinism for fights, gate before every commit, exact Fable 5.1 trailer, no commits by the controller while an implementer runs). Plus: `Meta` never references `document`; screens never mutate `Save.data` except through `Meta` functions; `Save.migrate()` upgrades v1 saves and is covered by a test; a headless `--e2e` harness flag runs the whole loop and exits 0.

```
Stats.derive(def, entry) -> {hp, atk}: hp = round(def.hp * (1+.25*(stars-1)) * (1+.10*(rank-1)) * (1+.01*(level-1))); atk same formula on def.atk
Stats.caps: stars 1..5; rank 1..(stars); level 1..(10*rank); xpToLevel(level) = 40*level
Crystal.KINDS = {basic:{cost:{units:0, gold:500}, odds:[[1,.70],[2,.25],[3,.05]]}, premium:{cost:{units:100}, odds:[[2,.60],[3,.32],[4,.08]]}}
Crystal.open(kind) -> {champId, stars, dup:boolean, shards?} ; pity: every 10th open of a kind guarantees the kind's TOP tier (fix-wave item 4, ruled: the plan's original "top-1 tier" line contradicted Task 4.2's own ">=3-star" checklist; a natural top-tier roll also resets the counter); uses RNG(Save.data.seed++); applies to Save (new champ, or shards on dup -- fix-wave item 5, ruled: shards scale by the rolled tier via Crystal.SHARDS_PER_TIER = {1:1,2:2,3:3,4:5}, not a flat 1; 5 shards -> +1 star up to 5, leftover kept)
FLOORS[i] = {floor, id, name, nodes, boss} (fix-wave item 9, ruled: each floor now carries its own id 'f1'/'f2', Phase 5 seam for an eventual tutorial floor 0); Quest.floorDef(n) -> the FLOORS entry with that .floor, or null -- looked up by field, not array index, and shared by Quest.floor/Rewards.forNode/G.startFight's {floor,node} sugar
Quest.floor(n) -> {floor, name, nodes:[{id, state, enc}], boss:{id, state, enc}} from FLOORS + Save.floors; Quest.canStart(n, k|'boss') (state open & energy ≥ 1); Quest.start(n, k) (spends 1 energy, returns encounter id); Quest.complete(n, k, won) (done → next node open; boss done → floor n+1 created open)
Rewards.mult = {gold:1, iso:1, xp:1} (fix-wave item 9, ruled: Phase 5 seam for a ratings/viewers multiplier -- applied once, inside forNode, not units)
Rewards.forNode(n, k|'boss') -> {gold, iso, xp, units?, cats?}: gold (160*n + 60*k) * Rewards.mult.gold (fix-wave item 8, ruled: raised from 100*n+40*k), iso 20*n * Rewards.mult.iso, xp 30*n * Rewards.mult.xp; boss adds units 50*n (not multiplied) and cats {enemyClass: 1}
Rewards.grant(r) applies to Save (xp → level-ups via Stats.xpToLevel, capped by rank)
Meta.SHOP_ITEMS = {basicCrystal:{cost, run:()=>Crystal.open('basic')}, premiumCrystal:{cost, run:()=>Crystal.open('premium')}, isoPack:{cost:{gold:200}, grant:{iso:60}}} (fix-wave item 9, ruled: Phase 5 seam replacing the old bespoke Meta.buyIso-only shape); Meta.buy(itemId) purchases from the table (refuses when short); Meta.buyIso() delegates to Meta.buy('isoPack'); the kiosk (Screens.renderShop) renders one card per entry
Roster.levelUp(id) (cost iso 10*level, level < cap), Roster.rankUp(id) (cost cats[def.cls] = rank, rank < stars), Roster.setActive(id)
Energy.now = () => Date.now() (injectable); Energy.tick() regens floor((now-ts)/360000) up to max; Energy.spend(1)
Arena.start() -> encounter for streak s: enemy cycles goblin→skeleton→hobgoblin→shaman→grub→grull→mother_rat, tier = t1 + floor(s/2) capped t5, hpMul 1+.08*s; Arena.record(won) updates streak/best, grants gold 60*s on a win
G.startFight({encounter, champ:'carl'}) clones p1 def with Stats.derive(def, Save.data.roster[champ]); G.mode ∈ 'exhibition'|'quest'|'arena'; on 'ko' → after slow-mo, G.onFightEnd(won) → Quest.complete/Arena.record + Rewards.grant → Screens.result(rewards)
Screens.show(name) toggles overlays; Screens.map/roster/crystal/shop/arena render from Meta only
harness: --e2e resets the save, opens 2 basic crystals (seeded), sets active carl, runs floor 1 node 0 and the boss with Ctrl.competent, asserts rewards/energy/roster changes, runs 3 arena fights, prints a JSON summary; exit 1 on any assertion/console error
```
